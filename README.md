## Getting Started

You can install the entire RIG Framework through txAdmin, follow the steps below:

1. Enter your server name.
2. On **Deployment Type** select **Remote URL Template**
3. Paste the this link **https://raw.githubusercontent.com/rig-fivem/txAdminRecipe/refs/heads/main/rig.yaml** into **Select Template**
4. Click next and continue with the setup steps
